# TryHackMe: Grand Larceny Auto — Walkthrough & Write-Up

- **Difficulty:** Medium / Hard
- **Category:** Reverse Engineering / .NET Assembly Analysis

---

## Overview

Grand Larceny Auto is a reverse engineering challenge where the objective is to analyze a game assembly (`GrandLarcenyAuto.dll`), understand its custom encryption and vault mechanism, determine the correct trigger parameters, and recover the hidden flag.

---

## Reconnaissance & Static Analysis

Upon exploring the challenge files, the main target assembly is located in the build data directory:

```bash
data_GrandLarcenyAuto_windows_x86_64/GrandLarcenyAuto.dll
```

Using IL disassembly or code inspection tools (`ILSpy`, `dnSpy`), we discover a core class named **`GrandLarcenyAuto.SafehouseVault`**, which handles an encrypted data blob field:

```csharp
private static readonly byte[] SealedBlob;
```

---

## Cryptographic & Logic Analysis

### 1. Key Derivation (`CryptoUtil::DeriveKey`)

The decryption key is generated by combining a constant salt string with an integer parameter representing the player's wanted stars:

$$
\\text{Salt} = \\text{"GLA::vault::key::v1::stars="} + \\text{stars}
$$

The key is then computed using **SHA-256** over the UTF-8 encoded salt string.

### 2. Unlock Criteria

Checking the vault rules, the target unlock threshold (`UnlockStars`) is explicitly set to **`6`**:

```csharp
private static const int UnlockStars = 6;
```

### 3. Decryption Routine

The vault decrypts `SealedBlob` by applying a byte-for-byte **XOR** operation against the derived SHA-256 key.

## Solution Script

Rather than trying to run the full game binary under Linux (which can cause platform graphics or Mono runtime crashes), we can write a custom C# loader script using **.NET Reflection** to load the DLL, trigger the static constructor to initialize `SealedBlob`, compute the key for 6 stars, and decrypt the flag automatically.

### `GetFlag.cs`

```csharp
using System;
using System.Reflection;
using System.Security.Cryptography;
using System.Text;

class Program
{
    static void Main()
    {
        // 1. Load the target game assembly
        Assembly asm = Assembly.LoadFrom("GrandLarcenyAuto.dll");
        Type vaultType = asm.GetType("GrandLarcenyAuto.SafehouseVault");

        // 2. Access the static field 'SealedBlob' (triggers static constructor .cctor execution automatically)
        FieldInfo blobField = vaultType.GetField("SealedBlob", BindingFlags.Static | BindingFlags.NonPublic | BindingFlags.Public);
        byte[] sealedBlob = (byte[])blobField.GetValue(null);

        Console.WriteLine($"[+] Extracted SealedBlob (length: {sealedBlob.Length})");

        // 3. Derive key for 6 stars based on CryptoUtil logic
        string salt = "GLA::vault::key::v1::stars=6";
        byte[] key;
        using (SHA256 sha256 = SHA256.Create())
        {
            key = sha256.ComputeHash(Encoding.UTF8.GetBytes(salt));
        }

        // 4. Decrypt via XOR
        byte[] decrypted = new byte[sealedBlob.Length];
        for (int i = 0; i < sealedBlob.Length; i++)
        {
            decrypted[i] = (byte)(sealedBlob[i] ^ key[i % key.Length]);
        }

        string flag = Encoding.UTF8.GetString(decrypted);
        Console.WriteLine($"\\n[***] FLAG: {flag}\\n");
    }
}
```

## Execution & Getting the Flag

1. Copy the game DLL to your working directory:

```bash
cp data_GrandLarcenyAuto_windows_x86_64/GrandLarcenyAuto.dll .
```

2. Compile and run the solution script using the Mono C# compiler:

```bash
mcs /reference:GrandLarcenyAuto.dll GetFlag.cs
mono GetFlag.exe
```

3. **Output:**

```text
[+] Extracted SealedBlob (length: 33)

[***] FLAG: THM{h0tf1x3d_my_0wn_w4nt3d_l3v3l}
```
